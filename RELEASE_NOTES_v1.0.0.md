# TailorTech v1.0.0

## Highlights

- Premium dark Material 3 Android app for men's measurement intelligence.
- Full Room-backed measurement schema with dual-unit display.
- Measurement Studio with:
  - Guided category workflows
  - Step-by-step guided session mode
  - Completion progress tracking
  - Required/optional and range validation badges
- Global size mapping across UK/US, EU, China/Asia, and country-specific view.
- Fit insights engine (drop, rise, thigh guidance).
- Gemini Outfit Advisor:
  - Paste product descriptions/charts
  - Receive fit recommendation and risk score
  - Risks and fit notes output

## Emulator-tested

- Built and run successfully on Android emulator `emulator-5554`.

## Notes

- Set `GEMINI_API_KEY` in Gradle properties to enable live AI calls.
